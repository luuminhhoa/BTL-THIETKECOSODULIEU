\section{Sơ đồ Thực thể Kết hợp (ERD)}

Dựa trên danh sách các thực thể và mối quan hệ đã chuẩn hóa, sơ đồ ERD ở mức quan niệm của hệ thống OctaPoint CaaS được thiết kế theo ký pháp chuẩn Chen:
\begin{itemize}
    \item \textbf{Thực thể mạnh (Regular Entity):} Biểu diễn bằng hình chữ nhật viền đơn.
    \item \textbf{Thực thể kết hợp / yếu (Associative/Weak Entity):} Biểu diễn bằng hình chữ nhật viền đôi (\texttt{Campaign\_Merchant}, \texttt{CreditTransaction}).
    \item \textbf{Mối kết hợp (Relationship):} Biểu diễn bằng hình thoi.
    \item \textbf{Thuộc tính (Attribute):} Biểu diễn bằng hình elip; thuộc tính khóa chính (PK) được gạch chân.
\end{itemize}
